- 修复从阅读器返回书签页后列表未立即刷新的问题
- 更新拷贝登录地址
- 移除自动选择模式以及多余功能
- 修复滚动模式下页面跳动问题
- 修复弱网环境下请求可能一直卡住不返回的问题
- 优化网络连接复用，减少请求耗时与资源占用
- 修复收藏、登录过程中快速退出页面可能导致的崩溃
- 优化阅读进度保存方式，大幅减少翻页时的磁盘写入
- 漫画详情缓存不再无限堆积，过期数据会自动清理
- 修复进入页面与下拉刷新同时触发时的重复请求
- 修复评论加载遇到服务端返回异常时直接崩溃的问题
- 修复线路测速失败后该节点被永久弃用、无法自动恢复的问题
- 修复在其他页面修改阅读器设置后，阅读界面不生效的问题
